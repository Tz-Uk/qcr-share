downloads live in `data/raw/` (git-ignored); the generated files are committed
so the app runs with no build step.

## Shia corpus (default): al-Mizan

Source: `tafsir_almizan_ar.db` from
[`app-furqan/quran-app-data`](https://github.com/app-furqan/quran-app-data),
an SQLite packaging of **Allamah Sayyid Muhammad Husayn Tabataba'i**,
*al-Mizan fi Tafsir al-Qur'an* (d. 1981). The packaging is **CC BY-ND 4.0**.

The database maps all 6,236 ayahs to 594 tafsir passages. `build-shia.mjs`
reads each passage, extracts every `(Surah: ayah)` reference from the Arabic
text, and joins it to the verses the passage comments on. Only verse-number
pairs are stored — no tafsir text is copied into this repository.

- 65,257 directed pairs
- 5,436 of 6,236 verses covered (87.2%)
- busiest verse: 352 links
- one relation category, `Quran by Quran`

The English al-Mizan database in the same repository is an AI-assisted
rendering, so the Arabic original is used as the source of truth.

> publicly would need the publisher's permission; do not make this repository

## Sunni corpus: Ibn Ashur

Source: `ar-tafseer-tahrir-al-tanwir-qbq.jsonl` from
[`ShahamFarooq/quran-bil-quran-connections`](https://huggingface.co/datasets/ShahamFarooq/quran-bil-quran-connections)
(Apache-2.0), an extraction of Ibn Ashur's *al-Tahrir wa al-Tanwir* (1964–1973).

Each source line names the verse commented on (`item_key`), the verse brought in
(`ayah_tag`) and the relation category. The build keeps directed pairs, drops
self-links, counts repeats as a weight (1–9), and keeps the most frequent
category for a pair that appears more than once.

- 21,112 directed pairs
- 5,439 of 6,236 verses covered (87.2%)
- busiest verse: 88 links
- 12 relation categories (Bayani, Siyaqi, Tafsili, …, Naskh)

## Quran text and translations

Arabic (Uthmani) and the two Sunni translations come from the
[Quran.com Content API v4](https://api.quran.com). The two Shia translations
come from [AlQuran.cloud](https://alquran.cloud):

- `/quran/verses/uthmani` — 6,236 Arabic verses
- `en.qarai` — Ali Quli Qara'i, phrase-by-phrase
- `en.sarwar` — Muhammad Sarwar
- `translation/19` — M. Pickthall, *The Meaning of the Glorious Koran* (1930)
- `translation/22` — A. Yusuf Ali, *The Holy Qur'an* (1934)
- `/chapters?language=en` — names, revelation place, verse counts, revelation order

Both Sunni translations are public domain. The Arabic text is the Quran itself.

## Rebuilding

```sh
npm run build:data   # Quran.com text, translations, Sunni corpus
npm run build:shia   # al-Mizan Shia corpus
npm test             # invariants for both corpora
```

`build:shia` downloads the ~4 MB al-Mizan archive, extracts it with `tar`, and
opens the SQLite file with Node's built-in `node:sqlite`.

## A note on meaning

A cross-reference is a reader's judgement that two passages belong together.
It is not a claim that they are equivalent, and it is not a tafsir of its own.
Use the app to find the connections, then read the surah and consult a
qualified teacher for understanding and rulings.
